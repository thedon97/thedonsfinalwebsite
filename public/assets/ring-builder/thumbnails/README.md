Place selectable option thumbnails here using this structure:

- `diamond-shape/{id}.svg`
- `setting-style/{id}.svg`
- `metal/{id}.svg`
- `head-basket/{id}.svg`
- `band-style/{id}.svg`
- `diamond-type/{id}.svg`
- `start-path/{id}.svg`
- `ring-size/{id}.svg`

If a thumbnail is missing, the builder automatically uses the generated SVG fallback.
